# 🌐 OmniSight – Global Intelligence Engine

**OmniSight** is an AI-powered intelligence dashboard that transforms any query into a 
rich, interactive visual report — complete with charts, metrics, tables, and summaries. 
Simply ask a question, and OmniSight dynamically generates a structured intelligence 
dashboard using Google Gemini AI.

🔗 **Live Demo:** [omni-frontend-376461558194.asia-south1.run.app](https://omni-izjq.vercel.app/)

## 🧠 Features

- 🔍 Ask any question — get a full visual intelligence dashboard instantly
- 📊 Dynamic charts, metrics, tables & summaries generated by AI
- 🤖 Powered by Google Gemini (`gemini-2.5-flash-lite`) for structured JSON output
- ✨ Smooth animations with Framer Motion
- 📈 Interactive data visualization with Recharts
- ⚡ Fast API responses with FastAPI + Uvicorn backend
- 🌐 Deployed on Google Cloud Run (backend) & Vercel (frontend)

---

## 🏗️ Architecture

```
User types a query
      ↓
Next.js frontend sends request via Axios
      ↓
FastAPI backend receives query
      ↓
Gemini AI processes query with system prompt
      ↓
Structured JSON returned (summary, charts, metrics, tables, sources)
      ↓
Frontend dynamically renders interactive dashboard
      ↓
Framer Motion animates widgets, Recharts renders graphs
```

## 🚀 Getting Started

```bash
git clone https://github.com/hina-ali651/omnisight.git
cd omnisight

# Frontend
cd frontend
npm install
cp .env.example .env.local
npm run dev

# Backend
cd ../backend
pip install -r requirements.txt
uvicorn main:app --reload
```

---

## 📌 Environment Variables

### Frontend `.env.local`

```env
NEXTAUTH_SECRET=your_secret
NEXTAUTH_URL=https://your-frontend-url.vercel.app
NEXT_PUBLIC_API_URL=https://your-backend-url
```

### Backend `.env`

```env
GEMINI_API_KEY=your_gemini_api_key
```
